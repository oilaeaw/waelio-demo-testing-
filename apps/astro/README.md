# @waelio-demo/astro

> 🚧 Coming soon — Phase 2/3

This app will demonstrate all `@waelio` packages in **astro**.
It follows the same 6 demo scenarios as all other apps.

## Scenarios
1. Reactive Store — `@waelio/ustore`
2. Storage Utilities — `@waelio/utils`
3. Local Database — `@waelio/data`
4. RealDB Collections — `@waelio/realdb`
5. Pub/Sub Messaging — `@waelio/messaging`
6. Edge Sync SDK — `@waelio/sync`
